# Dynamic Product Store
A dynamic product store web application built using HTML, CSS, and JavaScript.

## Features

- Fetches products from a REST API
- Dynamic product cards
- Search products
- Filter products by category
- Sort products by price and name
- Add products to cart
- Remove products from cart
- Clear entire cart
- Calculate cart total
- Save cart data using localStorage
- Loading and error handling
- Product count
- Responsive design
- Back to Top button

## Technologies Used

- HTML5
- CSS3
- JavaScript ES6+
- REST API
- Fetch API
- LocalStorage
